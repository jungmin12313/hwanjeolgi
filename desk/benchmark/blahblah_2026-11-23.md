- 표본: 최근 게시물 2편("꿈이 안 바뀐 사람들", "열심히 사는데 잘 안 풀리는 사람들") 표지·본문·에디터 장 6장
- 원칙: 원문은 저장하지 않는다. 구조와 패턴만 기록한다(인용은 몇 단어 이내).

## 1. 장 구성
표지(집단 라벨 질문형) → 1인 1장 인터뷰 × 3~4 → 에디터 장(일반화 명제) → 마지막 장 제작 앱 광고

## 2. 인터뷰 장 — 사람처럼 읽히는 이유

### 소개 문단 (약 5문장, 3인칭 전언 "~했다고 한다")
- **시간순 이력**: 어린 시절 계기 → 진학·시험(몇 번째 도전, 몇 년) → 현재 직장·연차 → 현재 마음 한 줄
- **모든 문장이 구체 사실**: 학년, 횟수, 연차, 기관 종류. 해석 문장이 없다.
- 마지막 문장만 현재 상태("요즘 ~하다고 했다")로 발언과 연결한다.

### 발언 (약 450자, 본인 말투)
1. 직답 또는 메타 서두(예: '이런 말 하면 유치해 보일 수도 있는데' 류)
2. 과거의 구체 행동(학원, 공부, 일찍 출근 등)
3. **전환 "근데 막상 ~니까"** — 두 편 모두 같은 전환으로 이야기가 꺾인다
4. 구체적 고충 1~2개(장소·행동이 있는 장면)
5. **굵은 글씨 1~2문장 = 감정의 핵심**, 끝에서 두 번째 위치
6. **결말은 미해결**: 현재 진행형 감정이나 '…'로 흐린다. 정리·교훈 없음.
- 어미: ~거든요 / ~더라구요 / ~했어요. 부사: 그냥, 좀, 진짜, 막상.
- 연결어미로 길게 잇는 구어 문장과 짧은 문장이 섞여 리듬이 불규칙하다.

### 헤드라인
발언 속 한 구절, 2줄, '…'로 끝나는 미완결형.

## 3. 에디터 장
- 제목: 일반화된 명제 + '…'
- 본문: 관찰 일반화 → "물론 ~" 양보 → **굵은 당위("~해야 한다")** → 수사 의문으로 끝
- → 조언·당위형. 환절기 원칙(조언·교훈 금지)과 다르다. **가져오지 않는다.**

## 4. 시각
흰 배경, 상단 로고, 가운데 정렬 굵은 헤드라인, 회색 아닌 검정 소개 문단, 이름만 색, 굵은 글씨 강조, 하단 이탤릭 쪽 번호. 표지는 드라마 스틸 등 타인 이미지.

## 5. 진위 관찰
인물은 이름만 나오고 출처·인터뷰 일자 표기가 없다. 매 편 구조가 동일하고 마지막 장이 카드뉴스 제작 앱 광고다. **실제 인터뷰인지 확인할 수 없다.** (판단하지 않고 기록만 한다.)

## 6. 환절기에 적용할 것 / 하지 않을 것

| 적용 | 하지 않음 |
|---|---|
| 소개 문단을 **시간순 구체 사실**로만 채우기 (공인 큐레이션의 소개 문단에 그대로 적용 가능) | 에디터 장의 당위·조언 결론 |
| 인용(발언)을 고를 때 **전환점이 있는 대목**을 고르기 | 타인 이미지(드라마 스틸) 표지 |
| 결말을 **현재 진행 중인 사실**로 두기 (정리하지 않음) | 출처 없는 인물 |
| 강조는 끝에서 두 번째, 감정의 핵심 문장 | 매 편 동일한 기계적 구조 |

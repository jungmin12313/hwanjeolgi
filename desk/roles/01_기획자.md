# ① 기획자

먼저 읽을 것: BRAND_TONE.md 0~1장, EDITORIAL_WORKFLOW.md 2·4장, 9장(해당 시리즈).

## 입력
발행인의 키워드·주제, 발행 예정일, 시리즈(형식).

## 할 일
1. 웹 검색으로 이 주제가 **지금** 다뤄지는 맥락(발표, 시상식, 통계 공개, 계절 사건)을 찾는다.
2. 서로 **다른 관점**의 기획안 2~3개를 쓴다. 같은 결론을 표현만 바꾼 안은 하나로 친다.
3. 각 안: 워크플로 부록 A-1 양식 + 근거가 된 사실 3개 이상(출처 링크).
4. 각 안마다 "이 안을 버린다면 이유"를 스스로 한 줄 적는다.

## 하지 않는 것
- 문장(카피)부터 쓰지 않는다. 표지 문구는 가안 한 줄만.
- 자료 없이 관점을 만들지 않는다.
- 주제를 기획이라고 부르지 않는다. ("겨울을 보내는 사람들"은 주제다.)

## 출력
`01_기획안.md`에 안 A·B·(C)를 순서대로.

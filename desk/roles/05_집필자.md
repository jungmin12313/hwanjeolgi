# ⑤ 집필자 (구성 + 집필)

먼저 읽을 것: **WRITING_GUIDE.md(블라블라 기준판, 최우선)**, `desk/benchmark/blahblah_2026-11-23.md`, BRAND_TONE.md, EDITORIAL_WORKFLOW.md 8-1.

## 1차 — 구성 (03_구성안.md)
- WRITING_GUIDE 5장에서 형식의 틀을 가져온다. 틀을 바꾸지 않는다.
- 장마다: 헤드라인 후보 / 소개 문단에 들어갈 사실(숫자 1~3개) / 말 문단에 쓸 원문 대목(전환점·장면 포함) / 굵게 쓸 문장.
- 여러 명이면 대비(세 번째 사람)를 확인한다.

## 2차 — 집필 (04_초고.md)
- 소개 문단: 이름으로 시작, 4~6문장, 200~260자, 전언 어미 돌려 쓰기, 해석·평가어 없음, 마지막은 말로 넘기는 다리.
- 말 문단: 직답 → 과거 행동 → 전환 → 장면 → 굵게(끝에서 두 번째) → 정리 없는 끝. 350~500자.
- 말의 출처는 WRITING_GUIDE 3-4 표대로 처리한다(연예인은 입말 되돌리기, 한 장 = 한 자리, 캡션 고지).
- 표지 후보 3개 이상 + 표지-본문 대응표(BRAND_TONE 6-2-1).

## 3차 — 블라블라 대조표 (필수)
- WRITING_GUIDE 7장 대조표를 장마다 채워 04_초고.md 끝에 붙인다. '아니오'가 있으면 고친 뒤 다시 채운다.
- 마지막으로 블라블라 게시물 1편과 번갈아 소리 내어 읽는다. 결이 튀는 문장을 표시해 고친다.

## 하지 않는 것
- 자료에 없는 장면·감정·대사를 지어내기. 원문에 없는 구어 표지를 끼워 넣기.
- 기록자 문단 안에 따옴표 인용을 홀로 세우기(말은 말 문단으로).

# ⑥ 비평 에디터 (독립)

앞 단계 대화 없이 **파일만** 받는다. 원고를 다시 쓰지 않는다. 수정안은 해당 문장에 한정한다.

먼저 읽을 것: **WRITING_GUIDE.md(블라블라 기준판)**, `desk/benchmark/blahblah_2026-11-23.md`, BRAND_TONE.md 6-2-1·8-1, EDITORIAL_CHECKLIST.md.

## 할 일
1. **블라블라 대조표 판정** — 집필자가 채운 WRITING_GUIDE 7장 대조표를 장마다 직접 다시 센다(문장 수, 글자 수, 숫자 개수, 종결 3연속 여부, 굵게 위치, 말 순서). 집필자 표를 믿지 않는다.
2. **나란히 읽기** — 벤치마크 파일 1-4·5-1·5-2의 패턴과 원고를 번갈아 읽고, 결이 튀는 문장을 표시한다.
3. **문제 문장 표** — | 원문 직접 인용 | 대조표 항목 | 블라블라라면 어떻게 썼을까 | 수정안 |
4. **표지 검수** — 상황 라벨 틀인가, 고유명사가 없는가, 대응표의 각 장이 표지 질문에 답하는가. 미달이면 대안 2개.
5. **사실은 따로** — 수치·날짜·인용 원문은 ④ 팩트체커와 나눠 보고 틀린 것만 적는다.
6. **판정** — 통과 / 경미한 수정 후 통과 / 퇴고 필요. 대조표에 '아니오'가 하나라도 있으면 통과가 아니다.

결과는 05_검수보고서.md 에 저장한다. 최종 판독은 편집장이 한다.

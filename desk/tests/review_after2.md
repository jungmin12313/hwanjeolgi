## 원고 1 — 연예인 큐레이션 본문 (진선규·박보경)

### 1. A~H 독립 검수

| 항목 | 판정 | 근거 |

| H 과도한 해석·감정 부여 | 문제 없음 | 눈물·웃음은 출처 서술 범위 안에 있다('터뜨렸다'를 '보였다'로 오히려 낮췄다). 10년과 8년이 어긋나는 부분도 해석하지 않고 각각 발화자를 밝혀 나란히 두었다. 박보경의 심리를 추측한 문장이 없다. |

### 4. 판정: **퇴고 필요**

사실관계와 구성은 통과 수준이다. 9장 기준 가운데 세 항목(자연스러움, 조사·어미, 문장 배치)이 1문단의 같은 원인 때문에 미충족이고, 9장은 "하나라도 어긋나면 퇴고"로 정하고 있다. 퇴고 범위는 위 표의 다섯 문장으로 한정하며, 구조를 다시 짤 필요는 없다. 특히 지침 5장이 직접 예로 든 '-다가/-면' 문장이 2차 수정 뒤에도 남아 있다는 점을 집필자에게 전달할 것.

## 원고 2 — 숫자 한 장 기록자의 말 「'쉬었음'이라는 칸」

### 1. A~H 독립 검수

| 항목 | 판정 | 근거 |
|---|---|---|
| A 사실의 정확성 | 경미한 문제 | 발표 기관(국가데이터처), 주기(매월), 조사명, 4주·1주 기준, 한국은행 이슈노트 시점(2026.1), 자료(한국고용정보원 청년패널조사), 대상(만 20~30세), 중소기업 48.0%, 유보임금 평균 3,100만 원이 모두 취재표와 일치한다. 다만 "(48.0%)"가 무엇의 비율인지 적혀 있지 않고, '곳'은 출처의 '기업 유형'보다 의미가 흐리다. 출처의 "육아·가사·취업 준비 **등**이 아닌 단순 휴식"에서 '등'이 빠졌지만, '휴식'이라는 적극적 기준이 남아 있어 정의가 틀어지지는 않는다. |
| B 논리적 연결 | 경미한 문제 | 1문단 끝 "그 사람이 어떤 일자리를 원하는지 알 수 없다"는 '쉬었음' 전체를 가리키는데, 2문단은 만 20~30세 청년만 답한다. 범위가 좁아진다는 신호가 없다. |
| C 조사와 어미 | 문제 없음 | '-이었고 … -이었다' 외에 같은 어미가 가까이 반복되는 곳이 없다. 1문단 둘째 문장의 '-지 않았고, … 보냈다고 답한'도 자연스럽다. |
| D 문장 내부의 정보 배치 | 문제 | "이 정도는 받아야 일하겠다고 여기는 연봉인 유보임금은"이라는 정의형 관형절이 주어를 감싸서 수치가 문장 끝에 늦게 나온다. 한 문장 안에 기업 유형과 유보임금이라는 두 정보가 '-이었고'로 묶여 있어 더 무거워진다. |
| E 문장 호흡과 가독성 | 경미한 문제 | 2문단 둘째 문장에만 정보가 몰려 있다. 나머지 문장들의 호흡은 적절하다. |
| F 문단 구성 | 문제 없음 | 정의 문단과 데이터 문단 두 개로 나뉘어 있고 분리할 이유도 분명하다. 결론 문장을 덧붙이지 않고 수치로 끝냈다. |
| G 상투적인 AI 표현 | 문제 없음 | 6-1 목록에 해당하는 표현이 없다. 제목의 '칸'도 본문의 '분류'와 대응하는 정도여서 과한 수사가 아니다. |
| H 과도한 해석·감정 부여 | 문제 없음 | '쉬었음' 청년의 심리나 사정을 상상한 문장이 없다. 필자의 판단은 "이 이름만으로는 … 알 수 없다" 한 문장뿐이고, 정의에 근거한 판단이다. |

### 4. 판정: **경미한 수정 후 통과**

9장 기준 여덟 항목을 모두 충족한다. 2문단 둘째 문장(D·E·A)과 '이름'→'분류' 용어 통일은 데스크 단계에서 고칠 수 있는 범위다. '등' 복원도 권고한다. 퇴고 단계로 되돌릴 사안은 아니다.

# 환절기 카드뉴스 제작 도구

@hwanjeolgi.mag 카드뉴스(1080×1350)를 만드는 정적 웹 도구. `index.html` 한 파일로 동작한다.

- 형식: 문답형 · 인터뷰형 · 에세이형
- 강조: `**굵게**`, `==굵게+계절색==`
- 되돌리기/다시하기 (Ctrl+Z / Ctrl+Shift+Z)
- 모바일 화면 대응, "사진에 전체 저장"
- 작업 내용 저장: claude.ai 링크에서 열면 계정에 저장(기기 간 동기화), 그 외에는 브라우저(localStorage)

배포: Netlify에서 이 저장소를 연결하면 빌드 설정 없이 바로 배포된다 (`netlify.toml`).
